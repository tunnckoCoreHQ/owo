# owo knowledge

This is owo's knowledge graph and the one description of its behavior: what an identity is, what the CLI does, how the code is laid out, and the decisions behind it. The terms it uses are defined in `GLOSSARY.md` at the repo root, one name per concept.

- [[model]] — What an identity is, its lifecycle, and how hosts use it
- [[formats]] — Owo dir and identity layout, entry types, frontmatter, state files and wikilinks
- [[cli]] — Commands, flags, output envelope and exit codes
- [[lint]] — Lint rules, levels, and what each checks
- [[architecture]] — Modules, data flow, and how an identity is loaded
- [[decisions]] — Implementation decisions; the general ones link their ADR in `docs/adr/`
